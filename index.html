Capaian Pembelajaran (CP)

"Peserta didik mengidentifikasi ragam gaya dan pemanfaatannya, serta menganalisis sistem tata surya, posisi, serta karakteristik benda-benda langit yang mengorbit Matahari."

Target Capaian Siswa (TP):

1

Mengenal Anggota Tata Surya

Siswa dapat menyebutkan Matahari sebagai pusat tata surya serta 8 planet utama dan benda langit lainnya.

2

Memahami Urutan & Ciri Planet

Siswa dapat mengurutkan letak planet dari yang terdekat hingga terjauh dari Matahari beserta keunikannya.

3

Rotasi dan Revolusi

Siswa mampu membedakan konsep gerakan planet mengelilingi Matahari (revolusi) dan berputar pada porosnya (rotasi).

Tentanga Media Pembelajaran Ini

Website Petualangan Antariksa ini dirancang khusus sebagai media pembelajaran inovatif mata pelajaran Ilmu Pengetahuan Alam dan Sosial (IPAS) Kurikulum Merdeka untuk siswa Sekolah Dasar kelas 4.

📌 Petunjuk Penggunaan bagi Siswa:

  • Gunakan menu navigasi di atas untuk berpindah materi tanpa reload halaman.
  • Klik tombol speaker pada kartu planet untuk mendengarkan suara penjelasnya!
  • Mainkan Kuis Interaktif untuk menguji pemahaman dan mendapatkan bintang emas.
  • Tantang dirimu pada Game Susun Planet untuk melatih logika urutan planet.

Versi Media: 2.0 (Single-file HTML)

Teknologi: HTML5, Tailwind CSS, JavaScript ES6, Web Audio API.
